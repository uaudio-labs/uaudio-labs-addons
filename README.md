# UA Labs Add Ons

Installable LUNA Add Ons from UA Labs. Each Add On is published as a `.lunaaddon` package on
this repo's [Releases](https://github.com/uaudio-labs/uaudio-labs-addons/releases) page. This repo
holds the packages only; it does not contain their source.

## Add Ons

| Add On | What it does | Needs LUNA | Latest |
|---|---|---|---|
| **MIDI Learn** | Map any MIDI controller to faders, plugin parameters and commands. Mappings are saved with the session. | 3.1.1 | [midi-learn-v0.4.0](https://github.com/uaudio-labs/uaudio-labs-addons/releases/tag/midi-learn-v0.4.0) |
| **ENVI** | Browse every instrument and preset you own, audition them on a track in your session, and play them with macro knobs and a live scope. | 3.1.2 | [envi-v0.3.3](https://github.com/uaudio-labs/uaudio-labs-addons/releases/tag/envi-v0.3.3) |
| **Files** | Browse drives, folders and files; audition sounds with a waveform and tempo-synced loops before importing; favorites saved globally and with the session. | 3.1.1 | [files-v0.2.0](https://github.com/uaudio-labs/uaudio-labs-addons/releases/tag/files-v0.2.0) |

## Install

1. Open the Add On's release and download its `.lunaaddon` file.
2. Double-click it to open it in LUNA.

## Releases

Each Add On is released on its own, tagged `<add-on>-v<version>`, so the Releases page lists
every Add On and every version from this one repo.
